# Demo — "Ye Aankhen" (original demo lines)

A 34 s silent demo rendered straight from the template's demo data: the original demo character, four look cards, and
19 short original lines (no song). It shows every shot kind the engine has.

- `demo-720p.mp4` — the film
- `contact-sheet.jpg`, `frame-*.jpg` — stills
- `preview-*.gif` — the doors opening, outfit flips, pain → relief
- `character-sheet.jpg`, `look-cards.jpg` — the character's expression set and look cards (made with Nano Banana 2.1)
- `film.json`, `character.json` — the files the engine rendered (the shot list was drafted by `tools/plan_shots.py`)
